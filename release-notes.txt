- Стиль Flyme: светлое и тёмное оформление в духе Flyme AIOS 2, собственная кнопка подключения, навигация и оформление вложенных разделов.
- Обновлены карточки, навигация, переключатели и переходы ColorOS. В ColorOS и Flyme повторные действия плавно меняют направление анимации, а системное отключение анимаций учитывается.
- Ядро Xray обновлено до 26.10.31. Upstream отключил MPTCP по умолчанию для уменьшения поверхности атаки; для исправления уязвимости ядра Linux требуется отдельное обновление операционной системы сервера.
- Сборка проверяет AAR Xray по закреплённой контрольной сумме, в том числе при восстановлении из кэша. Локальный SOCKS-вход остаётся на 127.0.0.1 с паролем.
- VLESS с поддерживаемым собственным шифрованием больше не помечается как незашифрованный только из-за отсутствия TLS. В списке узлов показывается конкретная причина предупреждения. Старые JSON с неполными данными требуют обновления источника для повторной оценки защиты.
