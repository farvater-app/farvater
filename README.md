# Farvater

Фарватер — открытый VPN-клиент для Android на базе Xray-core.

## Что такое Фарватер

Сервер выбираете вы. Фарватер не предоставляет серверы и не продаёт доступ.

## Возможности

- VLESS, VMess, Trojan, Shadowsocks и Hysteria2.
- Тестирование узлов, автопереключение при сбое.
- [Импорт подписок](#подписки-и-узлы), [раздельное туннелирование](#маршрутизация).
- Интерфейс: русский, английский, персидский.

## Установка

Android 8.0+. APK скачивайте только из [GitHub Releases](https://github.com/farvater-app/farvater/releases/latest). Большинство телефонов: `arm64-v8a`, 32-битный ARM: `armeabi-v7a`, Intel: `x86` или `x86_64`. Универсальный вариант: `universal`.

Возьмите APK и `SHA256SUMS.txt` одного выпуска. Пример для [v1.0.33](https://github.com/farvater-app/farvater/releases/tag/v1.0.33):

```sh
sha256sum --check --ignore-missing SHA256SUMS.txt
apksigner verify --print-certs Farvater-1.0.33-arm64-v8a.apk
```

Ожидаемый результат: `OK`. Сверьте SHA-256 сертификата подписанта без учёта двоеточий и регистра:

```text
D8:80:FC:FE:51:D4:A3:06:A5:0F:B8:67:40:83:9D:74:75:37:53:D4:88:06:6B:27:E1:54:00:B5:42:BC:68:0F
```

## Быстрый старт

1. В «Источниках» добавьте подписку или узел.
2. В «Узлах» выберите сервер.
3. Нажмите «Подключиться».
4. Разрешите VPN в диалоге Android.

## Подписки и узлы

По URL подписки загружается список серверов. Не публикуйте ссылку: возможна утечка токена. Импортируются ссылки отдельных узлов и [совместимые конфигурации Xray JSON](docs/subscriptions.md). Публичный каталог изначально выключен.

## Маршрутизация

Исключённые приложения обходят `VpnService`. Для домена, IP или подсети действует первое совпавшее [правило](docs/routing.md): VPN, напрямую или блокировка. По умолчанию российские сервисы из списка идут напрямую.

## Безопасность

Клиент проверяет TLS-сертификаты и фильтрует заведомо небезопасные публичные профили. Поддерживается DNS-over-HTTPS. SOCKS-прокси доступен только на `127.0.0.1` по паролю. При обновлении проверяются хеш APK, пакет, версия и подпись.

Оператор видит незашифрованный трафик. VPN не гарантирует анонимность, доступность сервисов, защиту скомпрометированного устройства или добросовестность оператора. [Подробнее](docs/security.md)

## Конфиденциальность

Без регистрации, рекламы, аналитики и автоматических отчётов о сбоях. Личным подпискам передаются HWID установки, модель и версия Android. Отправку можно отключить. Каталог получает запросы без HWID-заголовков. [Политика конфиденциальности](legal/privacy.txt)
