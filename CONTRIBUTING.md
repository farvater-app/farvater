# Участие в разработке

Спасибо, что хотите помочь Фарватеру. Ниже написано, как сообщить об ошибке, предложить идею и прислать изменения.

## Ошибки

Перед тем как создать issue, проверьте две вещи: стоит ли у вас последняя версия и нет ли уже такого же сообщения в [списке issues](https://github.com/farvater-app/farvater/issues).

Создайте issue по шаблону «Ошибка». Самое полезное в нём — шаги, по которым ошибку можно повторить. Не публикуйте ссылки на свои подписки, ключи узлов и HWID: это открытый репозиторий.

Об уязвимостях пишите на почту, порядок описан в [SECURITY.md](SECURITY.md).

## Предложения

Создайте issue по шаблону «Предложение». Опишите, какую задачу вы решаете, а не только какую кнопку хотите добавить. Так проще найти решение, которое подойдёт всем.

## Изменения в коде

Небольшие исправления можно присылать сразу. Перед крупными изменениями, например новым протоколом, новым экраном или сменой библиотеки, сначала создайте issue и обсудите идею, чтобы работа не пропала зря.

1. Сделайте форк и создайте ветку от `main`.
2. Внесите изменения и проверьте их на телефоне или эмуляторе.
3. Запустите тесты: `gradle :app:testDebugUnitTest`.
4. Откройте pull request и заполните шаблон.

Проверочная сборка GitHub Actions соберёт APK для всех архитектур, проверит его состав и сделает release-сборку с R8. Pull request принимается, когда все проверки прошли.

## Стиль кода

- Kotlin, официальный стиль JetBrains, отступ четыре пробела.
- Интерфейс на Jetpack Compose. Для новых экранов берите готовые компоненты из `ui/ios/Ios.kt` и цвета `IosColors`, чтобы всё выглядело одинаково.
- Комментариев в коде нет. Код должен объяснять себя сам: понятные имена функций и переменных, короткие функции.
- Тяжёлая работа — сеть, разбор подписок, проверка узлов — не выполняется в главном потоке.
- Новые строки интерфейса пишутся на русском, на «вы», без восклицательных знаков.

## Сообщения коммитов

Коротко и по-русски, что изменилось: `Подписки: обновление по одной`, `Исправлен разбор ссылок ss://`. Одна логическая правка — один коммит.
